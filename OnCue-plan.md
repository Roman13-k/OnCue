# OnCue — план

**OnCue** (от _on cue_ — «по сигналу / вовремя») — лёгкая Windows-утилита (Tauri + React), которая запускает приложения по расписанию: дни недели, окна времени, уведомления и отмена запуска.

## Статус: MVP готов

Ручные правила, уведомления, отмена, автозапуск с Windows, фоновая работа, минимальный UI.

---

## Дорожная карта

| Этап | Что дальше |
| ---- | ---------- |
| **v1.1** | Локальный сбор статистики использования (только с opt-in) |
| **v1.2** | Предложения правил на основе привычек (с % уверенности, без автозапуска без согласия) |
| **v1.3** | Сценарии дня, контекстные исключения (игра, батарея, DND), учёт частых отмен |
| **later** | Опциональный LLM-ассистент: настройка расписания на естественном языке |

ИИ не заменяет ручные правила — только предлагает улучшения. Обучение привычек остаётся локальным.
